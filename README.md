# 🎮 SLING — Neon Arcade Reflex Game

**SLING** is a fast-paced, neon-themed arcade reflex game built using HTML, CSS, and JavaScript. Navigate a glowing orb through challenging obstacles, collect golden orbs, maintain streaks, and push your reflexes to the limit as the difficulty increases over time.

## ✨ Features

* 🎯 **Reflex-Based Gameplay** — Steer the glowing orb through gaps and avoid obstacles.
* ⚡ **Progressive Difficulty** — Movement speed increases and gaps become narrower as you progress.
* 🟡 **Collectible Orbs** — Collect golden orbs to earn bonus points.
* 🔥 **Streak System** — Build consecutive successful passes to increase your score multiplier.
* 🌊 **Flow State** — Fill your flow meter to activate a temporary speed-control bonus.
* 🏆 **Achievements** — Unlock achievements by reaching milestones and completing challenges.
* 🎨 **Customizable Trails** — Unlock different trail colors using earned in-game currency.
* 📅 **Daily Challenges** — Track your daily progress and work toward new goals.
* 🎁 **Daily Rewards** — Spin for bonus in-game currency.
* 🔊 **Sound & Vibration** — Customize audio and vibration feedback.
* 📱 **Responsive Design** — Play on desktop, Android, and other supported mobile devices.
* 💾 **Local Progress Saving** — Save high scores, achievements, coins, and unlocked cosmetics in your browser.
* 🌌 **Neon Visual Effects** — Enjoy glowing particles, animated backgrounds, smooth transitions, and interactive UI effects.

## 🕹️ How to Play

1. Open the game and tap **START FLOW**.
2. Swipe or move your pointer left and right to steer the glowing orb.
3. Navigate through the gaps between obstacles.
4. Collect golden orbs to earn bonus points.
5. Avoid collisions to keep your run alive.
6. Build streaks and collect rewards to improve your score.
7. Beat your personal best and unlock achievements.

**Tip:** Stay focused! The game becomes progressively more challenging as your run continues.

## 🛠️ Technologies Used

* **HTML5** — Game structure and interface.
* **CSS3** — Responsive layout, animations, neon styling, and visual effects.
* **JavaScript** — Game mechanics, collision detection, scoring, difficulty progression, and interactions.
* **HTML5 Canvas API** — Real-time game rendering and animated effects.
* **Local Storage API** — Persistent local game progress.
* **Web Audio API** — Procedurally generated sound effects and ambience.
* **Vibration API** — Optional tactile feedback on supported devices.

## 🚀 Getting Started

### Play Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/sling-arcade-game.git
   ```

2. Navigate to the project directory:

   ```bash
   cd sling-arcade-game
   ```

3. Open `SLING_Interactive_Animations-1.html` in your web browser.

No additional dependencies or installation steps are required.

### Play Online with GitHub Pages

1. Open your GitHub repository.
2. Navigate to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose your main branch and the root folder.
5. Click **Save**.

For a cleaner published URL, rename the HTML file to `index.html` before enabling GitHub Pages.

Your game will be available at:

`https://YOUR-USERNAME.github.io/sling-arcade-game/`

Replace `YOUR-USERNAME` with your GitHub username.

## 💾 Progress & Data

SLING uses browser Local Storage to save game progress, including:

* Best score and cumulative score
* Earned in-game currency
* Achievements
* Unlocked and selected trail colors
* Daily challenge progress
* Best-run ghost trail
* Gameplay settings

**Note:** Progress is stored locally in your browser. It does not automatically synchronize between devices or browsers. Clearing browser storage may erase saved progress.

## 📱 Compatibility
